# Beta scope: questions for the owner

Each line gives the question, then what the code does today. Changing an answer is one edit
in `launch-garments.ts` or one environment variable.

## Garments offered for new designs

- Should joggers and track pants be offered at launch? The guide (pages 6 and 7) lists neither
  in the launch nine nor in a later wave. Today both are offered, because only leggings, sports
  bras and compression tops were named to hide.
- Should the sleeveless vest be offered beside the singlet? The guide names "reversible or
  single singlet". Today both are offered.
- Is a compression top the guide's "rash guard" (wave 2)? Today it is hidden as wave 2.
- Socks and the hockey skort are launch products in the guide but the studio has no garment
  for them yet. Building them needs measurements and drawings from the owner (A5, A6).

## The 3D view

- The "Show in 3D" button is hidden unless `SHOW_3D=true` is set on the server. The guide
  (module 4) wants a 3D preview; the trial waits for your verdict (A10). Turn it on when the
  verdict is yes.
