# Questions for the owner or a factory about size charts

Each line is a question, with what the code does today beside it.

1. Is the plus or minus tolerance one value per point, or does it differ above and below? Today: one value per point, used both ways. **Answered 2026-09-30: one value, as built.**
2. When a brand types one value, should the other sizes keep the chart's steps, or the chart's ratios? Today: the chart's steps, added to or taken from the typed value, and the result is marked as worked out from it. **Answered 2026-09-30: keep the chart's steps, as built.**
3. Is there one base size for a whole chart, or does it differ for each point of measure? Today: one base size for the whole chart.
4. Is a grade step of zero ever correct, for example a collar height that stays the same? Today: zero is allowed. Negative steps in the owner's file are refused.
5. Sports bras use their own size run, marked with the sports bra size system in the registry. A size run with no system is the usual run of its wearer. Is one sports bra run for women and one for youth right, or do some brands size sports bras on the usual women's run? Today a sports bra chart on the usual women's run is refused with a plain reason.
6. The Knitwright starter charts (2026-10-13, `docs/sizing/starter-charts.md`) use one chart for every fit, one size run for each wearer (men XS to 3XL, women XS to 2XL, youth YXS to YXL) and tolerances of 0.2 to 1.5 cm by point. Should a factory's numbers replace any of them before launch, and do slim and relaxed fits need their own charts? Today: one chart for every fit, with a note on the table that says so.
