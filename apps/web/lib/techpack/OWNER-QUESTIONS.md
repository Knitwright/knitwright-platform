# Tech pack document: questions for the owner or a factory

Each line is a question, with what the code does today beside it.

1. Is this the right order of sections? Today: cover, flats, measurements, how to measure, components, construction, colourways, artwork, labels and packing, suggested values, sign-off.
2. Is one row for each point of measure right, with the tolerance shown once for the row? Today: yes. The tolerance is the same at every size, because a chart gives one tolerance for each point.
3. Should the measurement table show the value for every size, or only the base size and the grade? Today: every size.
4. The drawings show the first colourway only. Should each colourway have its own drawing? Today: no, the colourways section lists them all.
5. Callout codes are A, B, C in the order of the table, which is grouped by section (body, sleeve, neck and collar, placket). Would your factory rather have codes in the order of the registry?
6. A seam class or stitch class that comes from the registry rule is shown as "Proposed by Knitwright. Not confirmed by anyone.", in the attention colours, with that sentence on every seam row. It is listed on the suggested values page under its own heading and counted apart from empty fields and suggestions. It stops being a proposal when the user chooses a class. Is that the right way to treat a proposal?
7. The suggested values page lists a measurement once for each source, with the sizes it covers, and the tolerance apart. Is that the level of detail a brand wants?
8. "Made by" in the revision history says "Not recorded". The database keeps who saved each version but there is no name to show yet. Should the history show a person's name, an email address, or "You"?
9. The sign-off block is always empty. What should it hold when reviewer sign-off arrives: a name, a date, a role, a signature image?
10. The count of "things to confirm" counts a row, not a cell: a measurement with gaps at three sizes counts once. Is that what a brand expects to see?
11. The document holds no price, no cost and no quantity that the user did not type. Are there fields a factory would expect on the front page that are missing, such as a factory name, a delivery date or a target price?
12. When no field is empty, the top of the page says "No empty fields. Suggestions and proposed stitching are still not confirmed by anyone." It never says that nothing is left to confirm. Is that the right wording?
13. A brand can mark a part such as a label as not used, which removes it from what is still to be confirmed. Should a seam be markable as not used in the same way?
