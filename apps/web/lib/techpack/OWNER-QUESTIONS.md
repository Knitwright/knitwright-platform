# Tech pack document: questions for the owner or a factory

Each line is a question, with what the code does today beside it.

1. Is this the right order of sections? Today: cover, flats, measurements, how to measure, components, construction, colourways, artwork, labels and packing, suggested values, sign-off.
2. Is one row for each point of measure right, with the tolerance shown once for the row? Today: yes. The tolerance is the same at every size, because a chart gives one tolerance for each point. **Answered 2026-09-30: one tolerance value, as built.**
3. Should the measurement table show the value for every size, or only the base size and the grade? Today: every size. **Answered 2026-09-30: every size, as built.**
4. The drawings show the first colourway only. Should each colourway have its own drawing? Today: no, the colourways section lists them all. **Answered 2026-09-30: one flat drawing per colourway.** Built: the colourways section draws the front of each colourway, without callouts (the flats section keeps them), on the page and in the PDF; the SVG files draw the colourway chosen on the page, and a design with several colourways names the colourway in the file name (`KW-001-v3-Away-front.svg`). The Excel file holds no drawings, as before.
5. Callout codes are A, B, C in the order of the table, which is grouped by section (body, sleeve, neck and collar, placket). Would your factory rather have codes in the order of the registry?
6. A seam class or stitch class that comes from the registry rule is shown as "Proposed by Knitwright. Not confirmed by anyone.", in the attention colours, with that sentence on every seam row. It is listed on the suggested values page under its own heading and counted apart from empty fields and suggestions. It stops being a proposal when the user chooses a class. Is that the right way to treat a proposal?
7. The suggested values page lists a measurement once for each source, with the sizes it covers, and the tolerance apart. Is that the level of detail a brand wants?
8. "Made by" in the revision history says "Not recorded". The database keeps who saved each version but there is no name to show yet. Should the history show a person's name, an email address, or "You"? **Answered 2026-09-30: the person's name from their profile, else their email address.** Built: the name is set in Settings (or comes from Google), kept in the sign-in profile, and read only for members of the brand; the page, the PDF and the Excel file show it. Someone no longer in the brand is "Not recorded".
9. The sign-off block is always empty. What should it hold when reviewer sign-off arrives: a name, a date, a role, a signature image?
10. The count of "things to confirm" counts a row, not a cell: a measurement with gaps at three sizes counts once. Is that what a brand expects to see?
11. The document holds no price, no cost and no quantity that the user did not type. Are there fields a factory would expect on the front page that are missing, such as a factory name, a delivery date or a target price?
12. When no field is empty, the top of the page says "No empty fields. Suggestions and proposed stitching are still not confirmed by anyone." It never says that nothing is left to confirm. Is that the right wording?
13. A brand can mark a part such as a label as not used, which removes it from what is still to be confirmed. Should a seam be markable as not used in the same way?

## Exports (step 9)

14. **Print resolution.** A picture in the PDF is shrunk so its longest side is at most 1600 pixels, no more than eight pictures are drawn, and the pictures in one file may add up to 4 MB. These are engineering limits chosen to keep a download quick and inside a small function. They are not print requirements. A picture that goes over a limit is drawn as a dashed box, and the document says so in words. Is 1600 pixels enough for the artwork your factories print, or do they need the original file? Do you want a print size in millimetres for each picture?
15. **What the Excel file holds.** Today it has nine sheets: Cover, Measurements, Components, Construction, Colourways, Artwork, Labels and packing, Suggested values and Sign-off. Each value has its source in the next column, in words. Lengths are numbers in centimetres. The plan named only the measurement table, the component list and the colourways. The drawings and the "how to measure" words are in the PDF only. Should the Excel file also hold the "how to measure" sentences, or the drawings as pictures? Would a factory rather have lengths in millimetres? **Answered 2026-09-30: the Excel file keeps every section, as built.**
16. **File names.** A file is named from the style number, or the design name when there is none, then the version and what it is: `KW-001-v3-tech-pack.pdf`, `KW-001-v3-front.svg`. Only letters, digits, hyphen and underscore are kept, so a name with accents or spaces has hyphens in it. Would you like the date, the brand or the colourway in the name?
17. **Page size and characters.** The PDF is A4 only. Is Letter needed? The font (Geist) has Latin and Cyrillic letters but no Chinese, Japanese, Arabic or emoji. Text a person types with such a character shows it as a question mark, and the cover says so. Do your brands write in any of those scripts?
18. **Drawings that are not to scale.** An SVG of a drawing that is not to scale has no callouts and says so inside the file. Is a drawing without values useful to a factory, or should the SVG not be offered until the drawing is to scale?
19. **Download record.** Each download is recorded with the design, the version, the format, the view, the person and the time. Nobody can see the record yet. Who should see it, and where: the brand owner on the design page, or only support?
