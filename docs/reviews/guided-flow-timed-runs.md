# Guided flow: five timed runs (plan step 15, task 6)

Owed to the owner. Acceptance: each run is under 5 minutes, or the slow stage is named.

## How to run

1. Sign in on a fresh browser profile. Start a timer when you press "Start a design, step by step".
2. Go through start, review, adjust and download without help. Note the time at the end of each step.
3. Stop the timer when the last of the four files (PDF, Excel, SVG front, SVG back) is saved.
4. Write down anything you had to guess, any word you did not understand, and anything that felt slow.

Use a real assistant key (A3) for at least three runs; the stand-in model is for tests only.
