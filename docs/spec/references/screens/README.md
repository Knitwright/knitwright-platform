# Reference screenshots (from the founder)

These are 136 screenshots of Kittl, Printify, Fabra and other tools, sent by the founder while the prototype was being designed. Personal details (account emails and names) are blurred.

- **Use them to match** layout, spacing, type sizes, hover and empty states.
- **Never ship** these tools' logos, artwork, template content or wording.
- **If a screenshot and the prototype differ:**
  - **layout and spacing:** follow the screenshot;
  - **anything Knitwright-specific** (garment boards, tech pack, Order, kit-safe fonts, factory locks): follow the prototype, `08-ui-kittl-shell.md` and `10-design-system.md`.
