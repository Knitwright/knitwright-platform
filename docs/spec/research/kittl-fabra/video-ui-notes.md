Method: each video was opened on youtube.com/watch (the /embed URL returned "Video player configuration error, Error 153", so the watch page was used). Captions: the English auto-caption track (ASR) was read directly from the player's own caption request, so caption quotes below are the actual auto-caption text (lightly trimmed), with the timestamp at which the caption line starts. ### Flow summary (Video 1)
1. Home → **+ NEW** / "Start designing" → Create a new design modal → pick Blank canvas, Products or Templates.
2. Products catalogue → filter (Type/Genders/Use cases/Aesthetics/Seasons/Collections) → pick a base product (icon marks "Edit this product's form").
3. Editor opens in 3D with Library toolbar; toggle 2D/3D/Tech pack views at the bottom.
4. Form toolbar / 2D: select pattern segment, drag nodes → **Simulate** → 3D updates.
5. Library: drop material on pieces → colours (Pantone/palettes) → repeat print (recolour, scale, padding, rotation) → placement graphic (remove background, size/position/rotation, print type).
6. Toggle tech-pack view → Measurements (Auto-map, add POMs, grade rules, tolerances per size) → Callouts → Materials/Artworks tabs; Specs toolbar measure tools draw POMs on 2D/3D.
7. Share (invite by email with Can view/Can edit, copy link) or Export (Tech Pack Excel, Images PNG/JPG with size and body/background toggles, Pattern DXF/PNG/JPG, Artwork, AI On Model, AI Flat Lay).
8. Add design to a Range plan board (groups, style cards with price/qty/sizes) → switch to Line plan table for quantities, WS/D2C split, cost, wholesale, RRP, profit totals.
9. Side tools: Repeat print maker → Publish to library; Mood board; Material Lab (prompt → 3 results → Use/Iterate → publish → apply in editor).

### Flow summary (Video 5)
1. Brand switcher → + Add brand → **Import your Brand**: paste website URL → Import (≈1 min) — or Create new manually.
2. Brand page auto-filled: Logos (incl. favicon), Colors (Primary/Secondary palettes), Fonts (Headline/Subheadline/Body/Accent, nearest Kittl match), Graphics (site product images), Visual style (Setting, Art direction, Rules & Boundaries from reference images). Brand completion % shown.
3. Edit: rename palettes/colours; swap fonts and weights; rename/add graphics; Edit Brand › Details (name, category, website, about) and **Voice and Tone** tags → Save.
4. AI Studio › AI Workflows › Marketing › **Product campaign kit**: upload product (or pick from brand graphics), Apply your brand (toggle + brand), logo, highlight text, campaign type, style tile, destination/aspect → Generate (15 tokens per image; generate again for more options).
5. Result → Image modal: prompt edit (15 tokens), Remove Background, Edit Area, Vectorize, Upscale, Add Text → Download, or Open in Editor.
6. In the editor, brand colours and brand text styles are one click away via the **Brand** tab in colour and font pickers.

- Left nav groups: workspace switcher → Products / Brand Kits / Projects (by type) / Library / Trash [V1]; Kittl: Create, AI Studio, Templates, Mockups, Projects [V5].

### Template catalogue
- Base-product catalogue with tabs **Blank Products | Templates**, a sort control, and facet filters with counts: **Type, Genders, Use cases, Aesthetics, Seasons, Collections** [V1]. For Knitwright, add Sport, Fabric/knit type and Fit (inferred).

### 2D/3D editor

### Flows/automation
